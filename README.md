A one-page newspaper front page summing up the world news of Friday 20 November 2026: the first Trump–Xi–Putin trilateral summit in Shenzhen and its four-point peace declaration, the International Court of Justice ruling that Myanmar committed genocide against the Rohingya, Anthropic's record Nasdaq debut, ballistic missiles over Kyiv, and COP31 closing in Antalya. The page is drawn in this session by `draw.py` from the day's verified news; `main.py` copies the finished page to `/output/entry.png`.

## Run it

```sh
python3 draw.py
python3 main.py
```
